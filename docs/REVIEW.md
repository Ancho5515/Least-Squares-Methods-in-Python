## 独立复核与回归修复

对数值实现、构建程序及20篇Notebook做了一次独立的只读复核。发现的问题均先复现，再修复并运行全套测试：

| 问题 | 修复及验证 |
|---|---|
| 大坐标掩盖其他坐标的有效步长 | 改为逐坐标相对步长；梯度不满足的小步仅报停滞，不报成功 |
| 最后一次迭代已经达标却报超预算 | GN、LM、狗腿和PWM均检查最终已评估状态 |
| 极小单位协方差的不对称被绝对容差掩盖 | 使用与整体单位缩放无关的相对对称性检查 |
| RLS大初始P发生相减消去 | 采用Joseph形式，验证连续两次更新及批量等价性 |
| 秩亏或活动边界仍输出参数置信区间 | 先检查数值满列秩和边界，条件不满足时明确省略区间 |
| PWM输入NaN、形状和容差检查不足 | 在测量前拒绝非法输入，按到包围盒的距离统一应用容差 |
| 清空输出或改变共享代码/CSV后仍能导出旧结果 | 执行时记录正文、输出和共享输入指纹，构建前验证 |
