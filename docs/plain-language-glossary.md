# 最小二乘白话词典

先给直觉，再给使用范围。比喻是理解入口，计算仍以正文定义为准。按问题分组查，不需要从头背。

## 我们在找什么

| 正式说法 | 简单解释 | 小例子或提醒 |
|---|---|---|
| 观测、样本 | 实际记录的一次输入和读数 | 第 2 秒的位置是 5.1 米 |
| 模型 | 暂时用来解释数据的规则 | 假设小车匀速：位置 = 起点 + 速度 × 时间 |
| 参数 | 模型里还要确定的设置 | 起点、速度；不要和已知的测量时间混淆 |
| 估计、拟合 | 从读数中找一组合适设置 | 合适取决于模型和评分，不等于发现唯一真相 |
| 预测 | 用选定设置算某次输出 | 可针对已有输入，也可针对新输入 |
| 残差 | 预测减观测，本书固定这个方向 | 预测 8、观测 10，残差 -2 |
| 噪声 | 同样条件下仍有的随机波动 | 固定物体反复称重读数不同；系统性偏差不能靠平均自动消除 |
| 损失、目标、cost | 把各种差距汇总成的评分 | 换评分规则，最合适的参数可能改变 |
| 最小二乘 | 让残差平方和最小 | “二乘”就是平方，不是两个数相乘就算最小二乘 |
| `arg min` | 找到让后面分数最低的设置 | 返回设置；`min` 返回最低分 |
| 线性 | 未知数只作已知零件的系数 | $a+bt+ct^2$ 对 $a,b,c$ 线性，图可以弯 |
| 非线性 | 未知数进入指数、分母等内部 | $a\exp(-kt)+c$ 对 $k$ 非线性 |
| 初值、迭代 | 从一组猜测开始，反复调整 | 不同起点可能走向不同局部结果 |
| 局部最小、全局最小 | 附近最低、所有允许位置里最低 | 到一个谷底，不代表已走遍所有山谷 |
| 约束、边界 | 明确允许哪些设置 | 速率不得小于零；不是事后随意裁剪 |

## 数据能告诉我们多少

| 正式说法 | 简单解释 | 小例子或提醒 |
|---|---|---|
| 向量、维度 | 一排数、这排有几个数 | 三参数模型的参数向量有 3 个分量 |
| 矩阵、设计矩阵 | 一张表、记录参数对各次预测的线性作用 | 每行观测，每列参数；矩阵乘法是按表计算 |
| 转置 $T$ | 交换表的行列 | 20×3 换成 3×20 |
| 列空间、投影 | 模型能给出的预测集合、其中离读数最近的位置 | 两次观测一个参数时，可用平面中的直线展示 |
| 正交 | 内积为零；非零向量可理解为垂直 | 最优线性残差与各列正交，不表示每次残差为零 |
| 秩、满列秩、秩亏 | 有多少独立变化、各参数列是否提供独有信息 | 复制同一列不会增加信息 |
| 可辨识性 | 数据能不能分清不同参数设置 | 只知道两袋总重，不能确定每袋重量 |
| 奇异值、SVD | 各种参数组合在读数中有多明显，以及把它们分开看的方法 | 很小的奇异值提示弱方向；还需考虑尺度 |
| 条件数 | 小扰动可能被放大得多厉害的敏感性指标 | 不是每次实际误差的精确倍数 |
| QR | 换成较好计算的垂直坐标，再求参数 | 可靠线性求解工具，不会新增测量信息 |
| 最小范数 | 多个同样好参数中，按所选长度规则挑最短者 | 不自动等于物理真值，依赖单位 |
| 正定、半正定 | 二次形状所有方向朝上、或允许平坦方向 | 只针对相应矩阵与局部模型，不能保证整个非线性问题全局只有一个答案 |

## 怎样安排下一步

| 正式说法 | 简单解释 | 小例子或提醒 |
|---|---|---|
| 导数、偏导 | 变化有多快、固定其他设置只动一个 | 导数也是带单位的变化率 |
| 雅可比 $J$ | 每个旋钮对每个残差的微小影响表 | 每行观测，每列参数 |
| 梯度 $g$ | 各个参数对总分的影响 | 负梯度在局部指向下坡，未必整段最快 |
| Hessian $H$ | 总分变化率如何再变化，即曲率 | 地形像碗还是像山顶的局部信息 |
| 线性化 | 把附近一小段弯曲规律暂时当直线 | 走远后要重新量地图 |
| 有限差分 | 试着左右动一点，用输出差估变化率 | 太小会受舍入、噪声和量化影响 |
| 步长、回溯 | 这次调多少、太远就缩小再试 | 有下降方向仍需检查实际效果 |
| 阻尼、LM | 给大步加费用，按效果调节限制 | 限制当前步，通常不改变最终原评分 |
| 信赖域 | 明确规定局部地图这次只管多大范围 | 半径不是参数的统计置信范围 |
| 增益比 | 实际改善除以局部预测改善 | 预测下降非正时不能直接套比值 |
| 停滞、收敛 | 卡着没动、在指定条件下趋近目标 | 小步和停止状态都不能单独证明真值或全局最优 |
| 正则化 | 把明确的额外偏好写入最终评分 | 与只限制走法的阻尼不同 |
| 缩放、归一化 | 按明确尺度换单位或刻度 | 不说明除以什么，就无法判断含义 |

## 读数和答案有多不确定

| 正式说法 | 简单解释 | 小例子或提醒 |
|---|---|---|
| 方差、标准差 | 波动的平方尺度、开方后的原单位尺度 | 标准差不是最大误差 |
| 协方差、相关 | 两个量是否倾向一起变 | 共同电源漂移可能让多个读数一起偏高 |
| 独立 | 知道一个结果，不增加对另一个结果的了解 | 一般比不相关更强，不能随意画等号 |
| 高斯、正态 | 一种钟形概率分布 | 许多小波动可近似，但不是所有噪声都符合 |
| 白化 | 换算误差，使协方差变成单位矩阵 | 处理波动尺度和相关性，不等于删点或自动独立 |
| 标准误 | 重复实验时，参数估计会散多开 | 与单次仪器读数的标准差不同 |
| 置信区间 | 按特定规则重复构造、具有相应覆盖率的区间 | 95% 不保证本次一定覆盖真值 |
| 预测区间 | 用于未来一次带噪声读数的范围 | 不同于平均响应曲线的置信带 |
| 先验、似然、后验 | 测量前的信息、参数下读数有多可能、结合数据后的信息 | 相关公式需说明噪声与先验假设 |
| 蒙特卡洛 | 多次随机模拟来观察统计规律 | 有限模拟次数本身也有误差 |

## 实验与工程词语

| 正式说法 | 简单解释 | 小例子或提醒 |
|---|---|---|
| 过拟合 | 连随机起伏也记成规律 | 训练分低，新题未必做得好 |
| 训练、验证、测试、留出 | 调参数、选方案、最后检查、暂不用于拟合的数据 | 反复用来选方案的数据不再是独立最终评估 |
| 稳健损失 | 对极大偏差不按平方那样快速加重处罚 | 降权以后仍要调查异常原因 |
| RMSE、MSE | 残差平方的平均值开方、或不开方 | RMSE 回到原单位；不同损失的 cost 不能直接排名 |
| 标定 | 用有规则的测量确定输入输出关系 | 合成实验不代表设备已经标定 |
| 递推、遗忘因子 | 来一条更新一次、逐渐给旧证据折扣 | 忘得快通常跟得快，也更容易抖 |
| 耦合 | 动一个输入，多个输出一起变 | 调红灯可能影响三个 XYZ 分量 |
| 量化、平台 | 只能走整数格子、动一段也没有明显输出变化 | 零导数不一定表示已达到目标 |
| 容差、预算 | 允许差多少、允许试多少次 | 次数用完不等于达标 |
| 可达性、色域 | 目标能否做到、设备能产生的颜色集合 | 各坐标分别未超限，不保证组合可达 |

查到一个词后，回到正文找它的条件和单位。解释通俗不代表可以省掉适用范围。
