# 中文最小二乘 Python 教材设计（已确认）

目标：面向有基础 Python、数学边学边补的自学者，以直觉、必要推导、可修改的实验和有答案的练习，理解并实现最小二乘方法。

正文采用 Jupyter Notebook，参考 Roger Labbe 的教学组织方式，原创讲解和实验；关键算法先展示计算过程，再与 NumPy / SciPy 对照。固定随机种子，章节各自在干净内核可完整运行。

00 阅读与运行指南；01 从求平均到拟合直线；02 建模；03 线性原理；04 QR/SVD 与数值稳定性；05 权重和不确定性；06 正则化；07 非线性基础；08 下降法与线搜索；09 Gauss–Newton；10 LM；11 信赖域与狗腿；12 真实数据、边界和稳健损失；13 递推最小二乘；14 综合标定；15 PWM→XYZ 校正。另有数学、算法速查、进阶方法与原书对应四篇附录。

参考资料：完整保留用户提供的中文 LaTeX 工程（含原有 audit）、工程自带 PDF、当前单独的中文版 PDF、英文原件及检查记录，集中于 references/nonlinear-least-squares/。对不同版本分别记录 SHA256，不以旧报告证明新文件的正确性。

Notebook 是教材正文的唯一来源。构建程序先执行各章，再从真实输入和输出生成整本中文 PDF，含目录、章节编号、公式、图表、页码与内部链接。PDF、执行后的 Notebook、数据、源码和验证报告均提交 Git。中间缓存不提交。

用户约束：不配置 GitHub Actions，不使用 Artifact；每个阶段和 bug 修复均独立 Git 提交；自主执行至可审阅初版。

取舍：独立教材适合补齐线性基础并服务工程学习；逐页重排原书不能承担此任务。旧译本保留其原始符号和已知疑点，教材明确自己的符号、算法与适用条件。PWM 实验只使用明确标注的合成模型，不宣称代表真实硬件。
