# 不熟悉公式，也能从这里开始

这份指南按“具体需要补什么”安排路线，不按学历给人分组。数学基础较少时，可以先理解问题和结果，再回头学推导；但要独立修改代码，还需要逐步学习 Python。

## 第一次，先完成一个很小的任务

1. 按 [README](../README.md) 安装工具，在项目目录打开 JupyterLab。
2. 打开 [00 阅读与运行指南](../notebooks/00-guide.ipynb)，从上到下点选代码格，按 Shift+Enter。文字格负责解释，代码格负责计算；运行中的格子会显示忙碌状态。
3. 看见 `[1. 2.]`，说出它们分别是起始值和每单位时间的增量。
4. 按本章提示把斜率改成 3，并同步修改自检预期，再运行。
5. 保存前，可以另存一份自己的实验本。改乱后重新打开原本，比在一堆已运行变量里猜哪里出错更容易。

先完成这一件事就够了。不要因为还不认识矩阵，连第一条直线也不敢试。

## 代码里这几个写法先认一下

| 写法 | 现在只需知道什么 |
|---|---|
| `t = ...` | 把右边的结果放进名叫 `t` 的变量；不是证明左右相等 |
| `np.array([1, 2, 3])` | 建一排可以一起运算的数 |
| `2*t` | 如果 `t` 是数组，就把每个数乘 2 |
| `def model(p):` | 给一段可重复的计算起名，缩进的内容是它的步骤 |
| `p[0]` | 取第一个数；Python 从 0 开始编号 |
| `A @ x` | 按计算表 `A` 和设置 `x` 算所有预测 |
| `plt.plot(...)` | 画线；`scatter` 画点；`xlabel`、`ylabel` 写坐标名 |
| `assert ...` | 检查作者预期；不成立就停下来提示，不是拟合算法的一部分 |

这些解释不替代 Python 入门课。若还不能独立分清循环、函数和数组，先读实验的文字与图，复制最小例子单独试，不必同时攻克编程和全部数学。

## 三种读法，按当前任务选

| 现在想做什么 | 建议顺序 | 先做到什么 |
|---|---|---|
| 看懂“拟合”在做什么 | 00 → 01 → 02，再读 05、06 的直觉部分 | 能说清参数、预测、残差，知道平均和直线各在解释什么 |

| 理解程序怎样一步步调 | 03、04 → 07 → 08 → 09 → 10 → 11 | 区分方向、步长、局部预测与实际改善 |

先读直觉不等于以后不需要数学。尤其解释参数区间、自己写导数或修改优化算法时，要回到推导和适用条件。附录A是按需工具箱，附录B用来选入口，附录C进阶选读，附录D保留来源和历史。

## 每章的四个动作

**先猜**：只用一句话预测改一个设置会怎样。

**再跑**：从本章第一格开始，先跑通原例，再一次只改一个条件。

**读结果**：指出图上每条线是谁、横纵轴是什么、打印的数在回答哪个问题。

**说理由**：把现象用自己的话解释；猜错也有价值，找出是哪个假设不对。

不要只比较“最后出来的图好不好看”。拟合分数低、参数测得准、预测新数据有效，是不同的判断。

## 卡住时先对照这里

| 现象 | 先做什么 |
|---|---|
| `NameError` | 从本章第一格重新执行；中间格可能依赖上面的变量 |
| `ModuleNotFoundError` | 确认依赖安装在当前所选内核使用的 Python 环境 |
| `AssertionError` | 读出是哪条预期未满足；改实验条件后，原例预期未必仍成立，别盲删所有自检 |
| 数值最后几位不同 | 先看偏差量级和自检；计算库和舍入可能不同 |
| 换数据后“成功”，但参数离谱 | 查单位、边界、信息是否足够和残差图，停止标志不是答案证明 |
| 看到陌生词 | 查[白话词典](plain-language-glossary.md)，再回原句确认它正在做什么 |

## 最小自测

不用背公式，尝试解释下面三句话：

1. 两次分别猜高 2、猜低 2，不能因相加为零就说没误差。
2. 只在起跑时拍很多张照片，仍不知道车速。
3. 程序把某个分数算到很小，也可能只是用了不合适的评分或模型。

如果能给出自己的例子，就有了继续读下去的基础。词典和答案是帮助学习的工具，翻查不算失败。
